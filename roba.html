🧪 المواد والتركيب الكيميائي

المادة التركيب الكيميائي التأثير
🧱 أسمنت بورتلانديC₃S + C₂S + C₃A + C₄AFقوة مبكرة ونهائية

🔬 سيليكاSiO₂ (غير متبلور) 85-90%مقاومة ضغط عالية

🌋 بوزولاناSiO₂ + Al₂O₃ + Fe₂O₃متانة عالية
⚛️ جرافينC (sp²)مقاومة خارقة

💡 ابتكارات كيميائية حصرية

خرسانة نانوية: أسمنت + سيليكا + جرافين → مقاومة 120+ MPa
خرسانة بوليمرية: أسمنت + ملدن + ألياف → مرونة عالية
خرسانة ذاتية الترميم: بوزولانا + سيليكا نانوية → إصلاح ذاتي
